# Proyecto: Piano Gigante

Este proyecto fue desarrollado por miembros de RESET durante el curso 2017/2018...[cite: 1]

## Especificaciones Técnicas
- **Controlador:** Arduino Mega 2560
- **Sensores:** Sensores de presión piezoeléctricos
- **Salida:** Sintetizador MIDI con altavoces autoamplificados
